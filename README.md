# Tougly

App para el celular que lleva el control de las hojas de cuero enviadas a La 30 para tougluar.

- La app está en esta carpeta (`index.html`, `app.js`, `styles.css`) y se publica con GitHub Pages.
- `google/Codigo.gs` es el programa que se pega en Google Sheets (Extensiones > Apps Script) para guardar los datos allí.
